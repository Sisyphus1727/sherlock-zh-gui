# 使用教程（中文 GUI + 命令行）

> 基线：Sherlock v0.16.2 · 481 个站点 · 示例用户名 `torvalds`，换成你要查的即可。
> 下文用 `<安装目录>` 指代你克隆的 sherlock 目录（例如 `D:\tools\sherlock`）。

---

## 一、图形界面（推荐，不用记命令）

**双击** `<安装目录>\启动图形界面.cmd`。

会开一个黑色窗口（这是服务本体，**不要关**）并自动打开浏览器 `http://127.0.0.1:8766/`。界面全中文，四步：

1. **填用户名** —— 一个或多个，空格/逗号分隔。
2. **选网站** —— 默认 12 个主流平台（约 10 秒出结果）；「全部站点」= 481 个；「自定义」可搜索勾选（中文名、英文名、域名都能搜）。
3. **点「开始查询」** —— 进度条、计时器在动，结果逐行出现；随时可「停止」。
4. **看结果** —— 每行：网站（含中文名）、状态、主页链接、耗时。可按状态筛选。

状态含义：

| 状态 | 含义 |
|---|---|
| **已注册** | 该站确实存在此用户名，链接即个人主页 |
| **未注册** | 该站没有此用户名 |
| **不支持此用户名** | 站点对用户名格式有限制（如不允许点号） |
| **被网站拦截** | 对方有反爬（Cloudflare 等），本次没查到 |
| **查询失败** | 网络超时或对方异常，**不代表账号不存在** |

报告：查询时自动存 TXT + CSV（高级选项里可勾 Excel），默认在 **`桌面\Sherlock报告`**，结果区下方有「打开报告文件夹」。

关闭黑窗口 = 退出程序，页面随之失效；下次再双击启动即可。重复双击不会端口冲突（已在运行就只再开一次浏览器）。

**浏览器没自动弹出？**

1. 双击 `<安装目录>\打开网页.cmd`（直接用 Chrome/Edge 打开界面）；
2. 或手动打开浏览器，地址栏粘贴 `http://127.0.0.1:8766/`（自动打开失败时地址已在剪贴板，Ctrl+V 即可）；
3. 看 `<安装目录>\gui\启动日志.txt`，里面有每一步尝试与结果；
4. 个别机器需要**以管理员身份运行**启动脚本，浏览器才允许被拉起。

前提是黑窗口还开着——它才是服务本体。

## 二、命令行：一条命令就能用

```bat
cd /d <安装目录>
sherlock.cmd torvalds
```

不给任何参数时，会把 `torvalds` 拿到**全部 481 个站点**上逐个检测，默认只打印**存在的**账号。全量一遍约 1.5 分钟。

想在任何目录都能用，把 `<安装目录>` 加进 PATH：

```bat
set PATH=<安装目录>;%PATH%
sherlock.cmd torvalds
```

## 三、只看几个站点（最快）

全量 481 站要一分多钟，多数时候只关心几个平台。用 `--site` 指定，可重复：

```bat
sherlock.cmd torvalds --site GitHub --site Reddit --site HackerNews
```

实测输出：

```
[+] GitHub: https://www.github.com/torvalds
[+] Reddit: https://www.reddit.com/user/torvalds
[+] HackerNews: https://news.ycombinator.com/user?id=torvalds
[*] Search completed with 3 results
```

> **站点名必须一字不差**：来自 `sherlock_project\resources\data.json`，区分大小写，含空格和括号。写错会得到
> `Error: Desired sites not found: 'Steam'.`
> 「Steam」不存在，正确的是 `Steam Community (User)` 与 `Steam Community (Group)`。

常用站点名（可直接抄）：

```
GitHub   Reddit   Twitter   Instagram   HackerNews   9GAG   1337x
About.me   Archive.org   BitBucket   Bluesky   Codeberg   Chess
Steam Community (User)   Steam Community (Group)
```

查名字怎么拼（模糊搜索）：

```bat
<安装目录>\.venv\Scripts\python.exe -c "import json;d=json.load(open(r'<安装目录>\sherlock_project\resources\data.json',encoding='utf-8'));print('\n'.join(k for k in d if 'steam' in k.lower()))"
```

（没建 `.venv` 就换成你的 `python`。）

## 四、看懂输出

| 符号 | 含义 |
|---|---|
| `[+] 站点: url` | 该站**存在**这个用户名（默认只打印这种） |
| `[-] 站点: Not Found!` | 不存在（需 `--print-all` 才显示） |
| `[*] Search completed with N results` | 统计，N 为命中数 |

两点说明：

- 开头 `A problem occurred while checking for an update: ...` 是它在查 GitHub 最新版本（网络不通就会报），**无害**。
- GitHub 站点常返回空结果（403/限流），不是命令写错。Reddit、HackerNews、Bluesky 较稳定。

## 五、六个常用场景

### 5.1 想知道哪些站点**没有**这个账号

```bat
sherlock.cmd torvalds --site Reddit --site "Steam Community (User)" --print-all
```

```
[+] Reddit: https://www.reddit.com/user/torvalds
[-] Steam Community (User): Not Found!
[*] Search completed with 1 results
```

### 5.2 一次查多个用户名

```bat
sherlock.cmd torvalds linus_torvalds --site Reddit --timeout 20
```

也支持从文件读（PowerShell）：

```powershell
sherlock.cmd (Get-Content users.txt) --site Reddit --csv -fo out
```

### 5.3 导出报告（txt / csv / xlsx）

```bat
:: 在当前目录生成 torvalds.txt 和 torvalds.csv
sherlock.cmd torvalds --site Reddit --site HackerNews --txt --csv

:: 再加 Excel
sherlock.cmd torvalds --site Reddit --xlsx
```

- `--txt` → 纯文本，一行一个链接
- `--csv` → 表格，列：`username, name, url_main, url_user, exists, http_status, response_time_s`
- `--xlsx` → Excel，URL 列是 `=HYPERLINK("...")` 公式，点开可跳转

> 输出落在**当前所在目录**（`sherlock.cmd` 不会切换工作目录）。

### 5.4 报告统一放进某个文件夹

```bat
sherlock.cmd torvalds linus_torvalds --site Reddit --csv --txt -fo D:\报告\sherlock
```

`-fo` 目录不存在会自动创建，每个用户名各一份 `{用户名}.csv` / `.txt`。

注意：`--xlsx` 不受 `-fo` 控制，始终写**当前目录**的 `{用户名}.xlsx`。

### 5.5 查「近似用户名」：`{?}` 通配

用户名里写 `{?}`，会分别替换成 `_`、`-`、`.` 各查一遍：

```bat
sherlock.cmd "torvalds{?}" --site Reddit --print-all
```

```
[*] Checking username torvalds_ on:
[+] Reddit: https://www.reddit.com/user/torvalds_
[*] Checking username torvalds- on:
[+] Reddit: https://www.reddit.com/user/torvalds-
[*] Checking username torvalds. on:
[+] Reddit: https://www.reddit.com/user/torvalds.
```

> 引号必须加，PowerShell 里 `{` `}` 是特殊字符。

### 5.6 走代理

```bat
sherlock.cmd torvalds --site Twitter --proxy socks5://127.0.0.1:1080 --timeout 20
sherlock.cmd torvalds --site Twitter --proxy http://127.0.0.1:7890 --timeout 20
```

## 六、参数速查

| 参数 | 作用 |
|---|---|
| `USERNAMES...` | 一个或多个用户名（**位置参数**，没有 `--username`） |
| `--site / -s NAME` | 只查指定站点，可重复 |
| `--timeout / -t N` | 单请求超时秒数，默认 60；建议 15~20 提速 |
| `--txt` | 输出 txt |
| `--csv` | 输出 csv |
| `--xlsx` | 输出 xlsx（始终写当前目录） |
| `-fo / --folderoutput DIR` | 输出目录（txt/csv） |
| `-o / --output FILE` | 指定输出文件名（单用户名 + `--txt` 时有效） |
| `--print-all` | 同时打印未命中的站点 |
| `--print-found` | 只打印命中（默认行为） |
| `--nsfw` | 包含 NSFW 站点 |
| `--proxy / -p URL` | 代理，如 `socks5://127.0.0.1:1080` |
| `--browse / -b` | 查完用浏览器打开所有结果 |
| `--local / -l` | 强制使用本地 data.json |
| `--json / -j FILE` | **载入**自定义站点数据（不是导出格式！） |
| `--dump-response` | 打印原始 HTTP 响应，排查误报用 |
| `--ignore-exclusions` | 忽略上游排除规则（可能增加误报） |
| `--verbose / -v` | 调试信息 |
| `--no-color` | 关闭彩色输出（重定向到文件时建议加） |
| `--version` | 版本信息 |
| `-h / --help` | 帮助 |

## 七、完整实战示例

```bat
cd /d <安装目录>

:: 1) 先快速看几个关键平台
sherlock.cmd suspect_name --site GitHub --site Reddit --site Twitter --site Instagram --timeout 15 --no-color

:: 2) 有命中就扩展变体
sherlock.cmd "suspect_name{?}" --site Reddit --site Twitter --timeout 15 --no-color

:: 3) 全量扫一遍并导出留档
sherlock.cmd suspect_name --csv --txt --timeout 20 -fo D:\报告\suspect
```

## 八、常见报错

| 现象 | 原因 / 处理 |
|---|---|
| `Error: Desired sites not found: 'Xxx'` | 站点名拼错或大小写不对，见第三节 |
| `unrecognized arguments: --username` | 没有这个参数，用户名直接写 |
| `ERROR: Problem while attempting to access data file '...'` | `--json` 是输入参数，别当输出格式 |
| 启动时 `checking for an update ...` 报错 | 访问 GitHub API 失败，忽略 |
| 某站点一直没结果 / 超时 | 该站不可达，加 `--proxy` 或换站点 |
| 命中多到离谱 | 用户名太常见，很多站点对任意路径都返回 200；用 `--site` 缩小并人工核对 |

更多见 [排错.md](排错.md)。

## 九、性能参考

| 场景 | 耗时 |
|---|---|
| 单站点 | 1~3 秒 |
| 3~5 个站点 | 3~10 秒 |
| 全部 481 站，`--timeout 30` | 约 80 秒 |
| 全部站点，默认 `--timeout 60` | 3~5 分钟（受不可达站点拖累） |

请求是并发的，瓶颈在少数慢站点，所以**调小 `--timeout` 提速最明显**。

# 排错

## 1. 浏览器没自动弹出

程序按 **Chrome → Edge → Firefox** 顺序尝试显式调用 exe，并且**只有服务端真的收到页面请求才算成功**。黑窗口会逐条打印：

```
正在尝试：chrome
[成功] chrome：页面已被浏览器加载
```

或

```
正在尝试：msedge
[失败] msedge：5 秒内没收到页面请求（进程数 0 → 0）
```

处理顺序：

1. **确认黑窗口还开着** —— 它才是服务本体，关掉页面就打不开了。
2. 双击 `<安装目录>\打开网页.cmd`（不经 Python，直接用 Chrome/Edge 打开 `http://127.0.0.1:8766/`）。
3. 手动打开浏览器，地址栏粘贴 `http://127.0.0.1:8766/`（自动打开失败时地址已复制到剪贴板）。
4. 看 `<安装目录>\gui\启动日志.txt`，里面有每一步的时间、结果、进程数变化。
5. **以管理员身份运行**启动脚本 —— 个别机器上普通权限拉不起浏览器进程（表现为「进程数 0 → 0」或进程一启动就退出）。

如果只是想让页面能打开、不要自动弹浏览器，设环境变量：

```bat
set SHERLOCK_NO_BROWSER=1
启动图形界面.cmd
```

## 2. Edge 启动即退出

少数环境下 `msedge.exe` 被拉起后立刻消失（日志里 `进程数 0 → 0`），一个窗口都不留。这就是程序把 Chrome 排在 Edge 前面的原因。若机器上只有 Edge 且起不来，用 `打开网页.cmd` 或手动粘贴地址。

也可用 `SHERLOCK_BROWSER` 强制指定浏览器：

```bat
set SHERLOCK_BROWSER=C:\Program Files\Mozilla Firefox\firefox.exe
启动图形界面.cmd
```

## 3. 端口被占用 / 想换端口

默认 `8766`。重复双击不会冲突：检测到已在运行，就只再开一次浏览器。

换端口：

```bat
set SHERLOCK_GUI_PORT=8899
启动图形界面.cmd
```

换端口后记得用新地址访问（`http://127.0.0.1:8899/`），`打开网页.cmd` 里写死的是 8766，需手动改。

查谁占着端口：

```powershell
Get-NetTCPConnection -LocalPort 8766 -State Listen | Select-Object OwningProcess
```

## 4. 界面打不开 / 白屏

- 确认黑窗口没关、没报错退出。
- 浏览器强制刷新（`Ctrl+F5`）。
- 直接访问 `http://127.0.0.1:8766/api/health`，正常应返回类似
  `{"ok": true, "python": "...", "sites": 481}`。
- 若 `sites` 为 0：说明没读到 `data.json`，检查 `<安装目录>\sherlock_project\resources\data.json` 是否存在（上游未完整克隆）。

## 5. 启动报 `[错误] 没找到 sherlock_project 目录`

`gui\` 必须放在 sherlock 仓库**根目录**下，与 `sherlock_project\` 同级。用 `install.ps1 -Target <sherlock目录>` 安装可避免放错。

## 6. 启动时一行 `A problem occurred while checking for an update: ...`

上游在访问 `https://api.github.com/repos/sherlock-project/sherlock/releases/latest` 查新版本，网络不通就报这行。**无害，可忽略。**

## 7. 查询结果异常

| 现象 | 说明 |
|---|---|
| GitHub 查不到 | 上游对 GitHub 的检测常被 403/限流，非操作错误 |
| 某些站点永远「查询失败」 | 该站不可达（被墙或反爬）；缩短 `--timeout` 减少等待 |
| 「被网站拦截」 | Cloudflare 之类的人机校验，属正常限制 |
| 命中数量异常多 | 不少站点对任意用户名都返回 200，属上游已知误报；用 `--site` 缩小范围并人工核对 |
| 中文用户名查不到 | 多数站点只支持 ASCII 用户名 |

## 8. 依赖装不上

- **pandas 装成了 3.x**：`requirements.txt` 已限制 `<3`。上游代码按 2.x 接口编写。
- **stem 装不上**：它只有源码包，构建需要 setuptools 隔离环境。上游当前代码并未实际调用 `stem`，可以先注释掉再装。
- **pip 卡住不退出**（某些受限环境）：装完看到 `Successfully installed ...` 即可，用 `pip list` 或 `python -c "import pandas"` 验证。

## 9. 报告文件在哪

- 默认 `桌面\Sherlock报告`；桌面不存在（被 OneDrive 重定向或精简系统）时退回 `用户目录\Sherlock报告`。
- 界面里可以改输出目录，「打开报告文件夹」按钮直接定位。
- 命令行：`--txt/--csv` 写当前目录或 `-fo` 指定目录；`--xlsx` **始终写当前目录**（上游行为）。

## 10. 如何反馈

开 issue 时请附上：

- `gui\启动日志.txt` 的内容（含时间戳与每步结果）
- 黑窗口的完整输出
- Windows 版本、Python 版本、浏览器与版本
